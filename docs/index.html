Disable Electrum

A tiny Foundry VTT module for D&D 5e that removes electrum (EP) from every currency field, transfer dialog and price choice, without touching the values already stored in your world.

What it does

Many tables simply do not use electrum. The D&D 5e system still shows an EP box on every character sheet, in the currency-transfer and conversion dialogs, and as a choice in every item's price denomination. Players put coins in it by accident, loot gets priced in it, and the GM spends time cleaning up. Disable Electrum makes the whole denomination disappear from the interface.

Hidden on actor sheets

The EP currency field vanishes from character and NPC sheets, group sheets and any other sheet that shows system.currency.ep. The remaining coins keep their layout.

Hidden in currency dialogs

Transfer, award and conversion dialogs lose their EP amount field (amount.ep), so nobody can hand out or convert into electrum.

Removed from price choices

Every denomination dropdown (item prices, shop and loot dialogs, anything that offers ep as an option) has the electrum option disabled and hidden.

Nothing is deleted

Stored EP balances and items priced in EP stay exactly as they are in the database. Turn the module off and everything is back.

Works with other modules

It watches the whole page for new windows and sheets, so modules that render their own currency fields (loot sheets, shops, party sheets) are covered too, as long as they use the system's field names.

Zero configuration

No settings. Enable it and electrum is gone; disable it and electrum is back.

How it works

The module deliberately leaves CONFIG.DND5E.currencies.ep alone. Deleting the system's currency definition is the obvious approach, but it makes Foundry drop the EP value the next time any affected document is saved, which silently destroys data and can break items priced in electrum. Instead the module works purely on the rendered interface:

  • On ready it scans the page once, then installs a MutationObserver on document.body that catches every newly rendered element.
  • It also hooks renderApplicationV2, renderActorSheet and renderItemSheet so sheets are handled the moment they open.
  • Every input named system.currency.ep or amount.ep is hidden together with its label, marked aria-hidden and taken out of the tab order.
  • Every <option value="ep"> in a select is disabled and hidden.
  • A short stylesheet backs this up with display: none rules, so the fields never flash before the script runs.

The module does nothing at all when the active game system is not dnd5e.

What it does not do

  • It does not delete or convert existing electrum. If a character already has 12 EP, those coins stay in the database; they simply are not shown. Convert or remove them by hand first if you want a clean sheet.
  • It does not change encumbrance, conversion rates or any rule. It is interface only.
  • It does not stop a macro or another module from writing EP through the API.
  • It does not support other game systems; it is written for the D&D 5e system's field names.

Install

In Foundry's setup screen open Add-on Modules → Install Module and paste this manifest URL:

Or download module.zip from the releases page and upload it to The Forge or unzip it into Data/modules. Then enable Disable Electrum in the world's Manage Modules. To install a specific older version use https://github.com/teshaman/disable-electrum/releases/download/<version>/module.json.
